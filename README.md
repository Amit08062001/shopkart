# 🛒 ShopKart

Modern e-commerce frontend built with React, Vite and Redux Toolkit.

## 🚀 Live Demo
[View ShopKart]

## ✨ Features

- Product listing
- Product details
- Search
- Category filtering
- Sorting
- Wishlist
- Shopping cart
- Checkout
- Order history
- Login / Logout
- Protected routes
- User profile
- Edit profile
- LocalStorage persistence
- Responsive design
- GitHub Pages deployment

## 🛠 Tech Stack

- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- Lucide React
- CSS
- GitHub Actions
- GitHub Pages
